# FIC_DEV

**PROGRAMADOR DE SISTEMAS COM IA**

## DESAFIO PRÁTICO 1

# Central Inteligente de Atendimento e Comunicação Institucional

**Inteligência Artificial Generativa**

| | |
|---|---|
| Carga horária recomendada | 12 horas |
| Modalidade | equipe de até três estudantes |
| Conteúdos avaliados | Aulas 01 a 07 |
| Versão | 1.0 — 2026 |

> **Produto esperado**
>
> Protótipo reproduzível que receba solicitações fictícias em texto, áudio e imagem; extraia informações; gere minuta de resposta institucional; produza recurso de acessibilidade em áudio; crie uma peça visual identificada como conteúdo sintético; e mantenha evidências de validação humana, segurança e uso responsável da IA.
